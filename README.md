# Shandhanu Mohan — Portfolio

A responsive, static portfolio site built with HTML, CSS and a tiny JavaScript enhancement. No build step or dependencies required.

## Preview locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of `shandhanumohan.github.io`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Your site will be available at `https://shandhanumohan.github.io/` after GitHub Pages finishes deploying.

Review contact details, experience dates, and public-facing claims before publishing.
